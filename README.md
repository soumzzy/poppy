# Poppy

Poppies, symbols of remembrance and quiet strength, bloom stubbornly in disturbed earth. The first color to return after ruin.

This is a meditative HTML poppy field: ambient visuals for your second monitor or a moment of stillness between tasks. A single file, fully offline.

Switch between five visual modes (Dark, Light, B&W, Spring, and Cyanotype) to match your mood or the time of day.
